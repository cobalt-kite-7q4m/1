# CC MediaWeir · 流撷

**流媒体课程资源提取工具**

Windows 桌面客户端 · 解压即用 · 提供编译版本

</div>

CC MediaWeir（流撷）是一款独立开发的 Windows 桌面工具，用于浏览课程目录、
检索课时并将课程资源批量保存至本机。

---

## 主要功能

- 浏览账号下已购课程与课时列表，支持按名称检索
- 勾选课程或课时后批量下载，界面内显示进度、速度与结果反馈
- 下载所得文件保存于本机，可使用常用播放器离线观看
- 主题切换、DPI 自适应、会话日志查看与清空
- 设置项本地保存，开箱即用

## 系统要求

- Windows 10 / Windows 11，64 位
- 无需安装：下载压缩包后完整解压即可运行
- 使用前请在本机登录相应平台客户端，并确认对目标内容具备访问权限
- 使用过程中需要网络连接

## 下载与安装

最新版本请前往本仓库的 [Releases](../../releases) 页面获取。

1. 下载最新版本对应的 `.zip` 压缩包；
2. 将包内全部文件解压至同一目录，保持目录结构完整；
3. 按界面提示完成首次启动确认后即可使用。

请通过本仓库所列渠道获取程序文件。
